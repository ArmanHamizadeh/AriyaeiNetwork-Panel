# AriyaeiNetwork-Panel
AriyaeiNetwork یک پنل جامع و مدرن برای مدیریت سرور، استقرار خودکار تونل‌ها (Gost, Rathole, Hy2) و توزیع هوشمند اشتراک‌هاست. این سیستم با انقضای پویا (On First Connect)، فعال‌سازی BBR، مسیریابی آی‌پی پاک برای هوش مصنوعی (Gemini/ChatGPT) و ربات چندزبانه تلگرام توسط آرمین حامی‌زاده توسعه یافته است.
